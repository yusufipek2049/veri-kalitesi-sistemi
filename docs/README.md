# Dokümantasyon

Bu dizin, projenin tüm dokümantasyonunun tek kök navigasyon noktasıdır.

## Gereksinimler ve Mimari

- [Gereksinimler (SRS)](srs/) — Fonksiyonel gereksinimler, kullanım senaryoları, veri modeli, kabul kriterleri
- [Mimari](architecture/) — Mantıksal mimari, güvenlik, mimari kararlar, skorlama tasarımı
- [Backend](backend/) — Backend modül talimatları

## Veri Tabanı ve Test

- [Veri Tabanı](database/) — Alembic migration, SQLite kalıcılık envanteri
- [Test](testing/) — Test katmanı talimatları, görsel doğrulama stratejisi

## Operasyon ve Uyum

- [Operasyon](operations/) — Runbook'lar, sürüm yönetimi, yedekleme/DR, yetki gözden geçirme
- [Uyum Kanıtları](compliance/) — Audit, erişim, güvenlik testi, bildirim, sorun yönetimi kanıtları

## Proje ve İterasyon

- [Proje Hafızası](memory/) — Proje özeti, mevcut durum, karar kayıtları, ürün yetenek matrisi
- [İterasyonlar](iterations/) — Prototip kayıtları, laboratuvar notları, iterasyon şablonları

## Teknik ve Denetim

- [Teknik İnceleme](technical/) — Sistem mimarisi, domain model, API, güvenlik, deployment
- [Fonksiyonel Denetim](functional-audit/) — Mevcut/hedef yetkinlik analizi, gap envanteri, yol haritası
- [Tasarım](design/) — Frontend görsel tasarım sistemi
- [İş Akışı](workflow/) — Yürütme hiyerarşisi, iterasyon döngüsü şablonları
- [Ajan Promptları](agent-prompts/) — Denetim orkestrasyon ve doğrulama promptları
